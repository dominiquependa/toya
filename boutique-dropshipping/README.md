# Boutique dropshipping gratuite — MiloStore

Cette boutique est un starter kit statique pour lancer une boutique dropshipping sans abonnement mensuel.

## Ce qui est inclus

- Page boutique responsive.
- Catalogue de 12 produits tendance a tester.
- Filtres par categorie.
- Panier en localStorage.
- Bouton commande WhatsApp.
- Section strategie gratuite pour viser 100 euros par jour.

## Important

Il est impossible de garantir 100 euros par jour. Le resultat depend de :

- la qualite du fournisseur ;
- le delai de livraison ;
- la marge reelle ;
- le volume de trafic ;
- le taux de conversion ;
- la confiance du site ;
- les contenus publies chaque jour ;
- le SAV et les retours.

Le modele cible propose est :

```text
12 euros de marge nette x 9 ventes/jour = 108 euros/jour
```

## A modifier avant publication

Dans `script.js`, remplacer :

```js
const WHATSAPP_NUMBER = "33700000000";
```

par ton numero WhatsApp au format international, sans le `+`.

Exemple France :

```js
const WHATSAPP_NUMBER = "33612345678";
```

## Validation fournisseur

Avant de vendre un produit :

- commander un echantillon si possible ;
- verifier les avis clients ;
- verifier les delais reels ;
- verifier les frais de livraison ;
- demander photos/videos produit ;
- verifier retours et remboursements ;
- eviter les produits de sante avec promesses medicales ;
- eviter les produits dangereux, contrefaits ou reglementes.

## Routine gratuite pour generer du trafic

Publier chaque jour :

1. Une video probleme : "Tu as ce probleme ?"
2. Une video demonstration : avant/apres ou test.
3. Une video preuve : avis, reaction, usage reel.

Republier sur :

- TikTok
- Instagram Reels
- YouTube Shorts
- Pinterest Idea Pins

## Scripts videos rapides

Scene : cacher les croquettes, chien qui cherche, fin calme.

### Brosse anti-poils

Hook : "Si tu as un animal, regarde ca."
